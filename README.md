# AAKA-repository
Робота  з велосипедними станціями 

## Іменники й Дієслова

__Дієслова:__

  - є кілька станцій
  - стоять велосипеди 
  - буває звичайний або електричний
  - Клієнт має
  - може взяти
  - покататись
  - повернути велосипед 
  - коштує
  - списуються з балансу 
  - хоче бачити
  - велосипедів стоїть
  - грошей мережа заробила


__Іменники:__

  - станція
  - номер велосипеду
  - Імʼя клієнта
  - баланс 
  - повернення
  - час катання
  - ціна 
  - кількість велосипедів
  - прибуток

## Картки класів

**Станція**:

  Атрибути: велосипеди (список), прибуток
  
  Методи:
    видати велосипед
    прийняти велосипед

**Велосипед**:

  Атрибути: номер, тип - звичайний чи електричний , ціна за хвилину
  
  Методи:
    порахувати вартість (час катання)

**Клієнт**:

  Атрибути: ім'я, баланс
  
  Методи:
    взяти велосипед
    покататись
    повернути велосипед (списує гроші з балансу)
    показати баланс



Bike
Що він знає:
bike_id номер велосипеда
bike_type тип велосипеда: звичайний або електричний
station станція, на якій зараз знаходиться велосипед
is_available_for_rent чи доступний велосипед для оренди
вартість оренди за хвилину залежно від типу велосипеда

Що він вміє:
перевіряти, чи велосипед доступний для оренди
змінювати свою доступність для оренди
змінювати станцію, на якій знаходиться велосипед

Клас 
Station
Що він знає:
bikes велосипеди, які зараз знаходяться на станції.

Що він вміє:
додавати велосипед на станцію
видавати велосипед зі станції
приймати повернений велосипед
повертати кількість велосипедів на станції

Клас 
Client
Що він знає:
name ім’я клієнта
balance баланс клієнта

Що він вміє:
брати велосипед в оренду
оплачувати поїздку зі свого балансу
перевіряти чи достатньо коштів для оплати.


## Файли
  - Андрій - Усе, що стосується велосипедів і станцій
  - Каріна - Усе, що стосується клієнта та його балансу.
  - Аріна - Поїздки: взяти велосипед, повернути велосипед, порахувати вартість, облік загальної виручки мережі
  - Артем - Запуск: файл з функцією main(), тестові дані, звіт адміністратора та 2-3 перевірки через assert. Репозиторій створив Андрій
